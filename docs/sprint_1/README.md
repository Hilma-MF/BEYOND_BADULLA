# Sprint 1 — Foundation

Sprint 1 focused on establishing the foundation of the BEYOND BADULLA tourism system.

## Completed Work

- Flask project structure
- SQLite schema and automatic seed data
- 11 attraction records
- Tourist registration, login, and logout
- Password hashing
- Attraction browsing and detail pages
- Responsive foundation
- GitHub-ready requirements and README

## Sprint 1 Outcome

The initial Flask application, database structure, authentication system, and attraction browsing functionality were established as the foundation for the following development sprints.
