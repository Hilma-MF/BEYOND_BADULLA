# BEYOND BADULLA

Local tourism discovery and one-day visit planning system for Badulla, Sri Lanka.

## Stack
Flask + SQLite + HTML5 + CSS3 + JavaScript

## Features
- Tourist registration/login
- Attraction browsing, search and category filtering
- Attraction detail pages
- Google Maps links
- One-day visit planner
- Admin dashboard and attraction CRUD
- Responsive UI

## Setup
```bash
python -m venv venv
venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
